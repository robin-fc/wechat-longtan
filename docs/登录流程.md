登录流程

- 勾选隐私条款或在隐私弹窗中同意，写入本地 `privacyAccepted`
- 未勾选隐私时，点击任意登录按钮先弹隐私弹窗并终止后续流程
- 已勾选隐私且未登录：
  - 点击“微信授权登录”，调用 `wx.login` 获取 `code`
  - 调用后端 `login({ code })` 创建/登录账号，缓存 `accessToken`、`refreshToken`、`expiresTime`、`userId` 到本地，并写入 `isLoggedIn = true`
  - 登录失败时，使用后端返回的 `msg` 提示，如“微信登录 code 无效或已过期，请重新获取”
- 已登录但未绑定手机号：
  - 显示“微信授权绑定手机号”按钮，使用 `open-type="getPhoneNumber"` 获取 `phoneCode`
  - 调用后端 `postPhoneNumber({ phoneCode })` 换取手机号，缓存 `phoneNumber`、`purePhoneNumber`、`countryCode`，并写入 `phoneBound = true`
  - 绑定失败时，使用后端返回的 `msg` 提示
- 已登录且已绑定手机号但未完成资料：
  - 显示“微信授权头像昵称”，点击后展示 `showProfileModal`
  - 用户选择头像、填写昵称后点击继续
  - 调用后端 `updateUserInfo({ wxName, logo })` 更新资料，写入 `profileCompleted = true`
  - 关闭授权弹窗并跳转首页

异常与拒绝处理

- `wx.login` 或接口返回错误：根据后端 `msg` 进行提示并保持当前状态
- 用户拒绝手机号授权：不改变已有登录状态，`phoneBound` 仍为未绑定；按钮继续显示“微信授权绑定手机号”
- 用户未选择头像或未填写昵称：弹提示并阻止继续登录
- 更新用户信息失败：弹错误提示并记录错误日志

重入与状态驱动

- 状态键：`isLoggedIn`、`phoneBound`、`profileCompleted`、`privacyAccepted`
- 页面初始化与显示时根据本地缓存刷新按钮与流程分支
- 当 `isLoggedIn = true` 且 `phoneBound = true` 但 `profileCompleted = false`：再次进入页面或点击按钮会直接展示头像昵称授权弹窗，无需重复前置授权
