登录流程

- 勾选隐私条款或在隐私弹窗中同意，写入本地 privacyAccepted
- 点击“微信授权登录”按钮
- 若未勾选隐私条款，先弹出隐私弹窗并终止后续流程
- 已勾选且未登录时，触发微信手机号授权（getPhoneNumber），获取 code
- 调用登录接口 login({ code }) 创建账号并保存凭证到本地存储
- 弹出头像与昵称授权弹窗（showProfileModal）
- 用户选择头像、填写昵称后点击继续登录
- 调用更新用户信息接口 updateUserInfo({ wxName, logo })
- 关闭授权弹窗，跳转到首页

异常与拒绝处理

- 用户拒绝手机号授权：不创建账号，记录日志，保持在登录页
- 用户未选择头像或未填写昵称：弹提示并阻止继续登录
- 登录或更新用户信息失败：弹“登录失败”提示并记录错误日志

重入行为（已登录但未完善资料）

- 当手机号登录已成功（本地 isLoggedIn = true），但用户关闭或拒绝头像昵称授权：
  - 再次点击“微信授权登录”按钮时，不再触发手机号授权
  - 直接重新弹出头像昵称授权弹窗（showProfileModal），引导用户完善资料
  - 完成后写入 profileCompleted = true 并跳转首页
